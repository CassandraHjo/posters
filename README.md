# Academic Posters

A repository to store and organize all my academic posters.

## Structure

Posters are organized by year and conference/event:

```
posters/
├── YYYY/
│   └── conference-name/
│       ├── poster.pdf
│       └── poster.tex   (if applicable)
└── ...
```

## File Formats

- **PDF** — final poster files ready for printing or sharing
- **LaTeX / `.tex`** — source files for posters typeset with LaTeX
- **PNG / SVG** — exported images or figures used in the posters

## Adding a New Poster

1. Create a folder following the `YYYY/conference-name/` convention.
2. Place the poster file(s) inside that folder.
3. Commit and push the changes.
